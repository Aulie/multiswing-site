# MultiSwing — marketing site

The public landing page for MultiSwing, a dual-camera golf swing replay app
for iPhone and iPad. Served by GitHub Pages at
<https://aulie.github.io/multiswing-site/>.

The page is a single static `index.html` with no build step. It is generated
from the app repository's `web/` directory — edit it there and copy it here,
so the two don't drift.
