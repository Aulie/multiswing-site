Where the name appears

A session is two or three of the user's own devices linked over MultipeerConnectivity. Before filming starts the user gives each physical device a job — one iPhone down the line, another face on, and often an iPad showing the replay. The name is how the user tells those devices apart on screen while assigning those jobs.

1 · Accepting a device by name

An iPhone being asked to accept another iPhone. The confirm button is the device's name, and it is the only thing distinguishing the device requesting to join. Without the entitlement it reads "iPhone", which is what every iPhone in range also reads.

2 · Assigning roles across three devices

The session roster while connecting, in Three Devices · Dual-Angle. Each row is a physical device and the job it has been given. The user is matching these rows to the devices on tripods around them.

The same session from the iPad, accepting an iPhone by name.

3 · Named devices during capture

A dual-angle session running. The connected devices are named on screen so the user can see at a glance which of their devices is filming and which is replaying.

4 · Names the user has chosen to remember

Settings. "This device" shows the name this device advertises, and "Remembered paired devices" lists devices the user confirmed once so they reconnect without being asked again. That list is the only place the name is stored: locally, in UserDefaults, visible and removable here, and deleted with the app. It is never uploaded — the app has no server and no account.
